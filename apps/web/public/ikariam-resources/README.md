# Authentic Ikariam top-bar resource icons

These are the **original small resource icons** used in the Ikariam interface (including the resource bar), **not** the larger island-resource illustrations. They are kept locally as small WebP files, preserving the original transparent pixels, so the Daedalus interface does not make tracking requests to a third-party image host.

Source: Ikariam Fandom's original `small.gif` resource images (image server returned lossless small WebP copies), retrieved November 21, 2026:
