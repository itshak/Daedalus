# Design
Store a random 256-bit master key as one generic-password item. Derive record identifiers from service and slot and authenticate both with AES-GCM; files are owner-private, atomic and ciphertext-only. Retain existing per-account server envelope keys inside encrypted records so old server backups remain decryptable. Migrate legacy entries once on access, with the OS's existing ACLs intact; never overwrite or delete them automatically. A saved migrated entry avoids its former Keychain lookup. Forget explicitly removes the legacy item too. The parent and supervised Selenium child share the unlocked master only in anonymous local pipes and memory; the child returns the master only after successful unlock, and the parent caches it for the process lifetime. The helper remains killable. Explicit user denial is cached for the process lifetime to avoid repeated prompts; restart to retry. App updates, OS lock/revocation and legacy item ACLs may still require OS approval. Non-Mac credential behavior is unchanged.
