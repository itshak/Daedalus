# Fill city warehouse

## Why
An operator needs a simple one-time way to gather a selected resource from all other owned cities without knowingly exceeding the destination's actual free storage.

## What changes
Add a native desktop/web automation with destination and resource selectors, optional fleet selection, current incoming cargo accounting, a shared reviewed storage budget, and bounded per-load revalidation using the existing IkaBot transport engine. No automatic replay or repeated refill.
