## ADDED Requirements

### Requirement: Native task monitor parity
The native application SHALL offer the same logical task summaries, account scope, activity detail, statistics and recovery/receipt access through the versioned controller API, with accessible Qt/Fluent layouts.

#### Scenario: Operator reviews a recovered task on Mac
- **WHEN** the task is selected
- **THEN** the client presents the same observed cumulative statistics and execution runs as the website
- **AND** legacy controllers retain compatible limited-history presentation
