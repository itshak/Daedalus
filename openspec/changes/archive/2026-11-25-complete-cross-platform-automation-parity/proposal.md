# Delivered cross-platform IkaBot native workflow baseline

## Why
Replace raw automation configuration with dedicated desktop/web editors and account-scoped, reviewed operations.

## What Changes
- Versioned operation coverage manifest with registry drift tests and explicit partial or protected status.
- Native desktop and web editors for the reviewed supported subset, player-first account names, no editable JSON fallback.
- Account-bound inventory and reviewed tickets for construction, one-time shipments, donation, worker assignments, layout, new building, station, barbarian operations and vacation; independent per-account review queues.
- Recurring external consolidation recipient verification, notification tests, durable receipt history and protected administrative status.

All unresolved original implementation, test, administrative and release requirements move to the active finish-cross-platform-operation-parity change. No pending CI or real-game acceptance is marked passed. The original scope and target specs are preserved there. Existing overlapping changes remain active.
