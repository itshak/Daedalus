# Support and troubleshooting

Daedalus is an experimental beta project, not a production-ready IkaBot replacement. The current desktop GUI and backend have deliberate feature and security limits.

For installation and startup, begin with the [README](README.md). The [synthetic desktop demo](docs/SYNTHETIC-DEMO.md) is the safest way to verify your setup without live accounts. For macOS packaging, see [docs/MACOS-BUILD.md](docs/MACOS-BUILD.md). For what currently works, what is opt-in, and what remains incomplete, see [docs/PROJECT-STATUS.md](docs/PROJECT-STATUS.md).

For reproducible problems, open a [bug report](https://github.com/itshak/Daedalus/issues/new/choose) with your OS, Python version, installation steps, expected behavior, and **sanitized** error output. For enhancements, open a feature request. Questions about the upstream IkaBot engine itself may belong in the [upstream project](https://github.com/Ikabot-Collective/ikabot).

**Never paste live tokens, login details, cookies, account IDs, full production logs, or other sensitive information into public issues.** Report security vulnerabilities privately as described in [SECURITY.md](SECURITY.md). Volunteer maintainers cannot guarantee response times.
